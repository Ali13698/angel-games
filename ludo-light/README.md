# منچ سبک Angel

## وضعیت

این پوشه شامل منطق Go و رابط TypeScript است.
آماده‌بودن بازی آنلاین هنوز تأیید نشده است.

تمام خروجی‌های ساخت در همین پوشه ایجاد می‌شوند.
کد بازی فقط از `@angel/sdk` برای اتصال استفاده می‌کند.

## نیازمندی‌ها

- Node.js نسخه ۲۰ یا بالاتر و npm
- Go مطابق `go.mod`؛ در این پروژه `1.27`
- برای اتصال: SDK محلی سالم، سرور سازگار، اتاق و نشست معتبر

## پیش‌نمایش رابط

در ترمینال و داخل پوشه `ludo-light` اجرا کنید:
```sh
npm install
npm run build
npm run preview
